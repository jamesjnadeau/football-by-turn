# football-by-turn

## Superpowers plans

Implementation plans written by the superpowers skills live in `docs/superpowers/plans/`
and are **committed to the repository by default**. When a plan is written or revised,
commit it — don't leave it untracked, and don't wait to be asked.

Commit the plan on its own, with a `docs:` subject describing the plan
(e.g. `docs: the assignment-defense implementation plan`).
